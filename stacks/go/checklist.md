# Памятка Go

Жёсткие правила одной строкой. Разработчик держит её открытой во время работы и проходит по ней на самопроверке; подробности и примеры — по ссылке, когда пункт касается задачи. Памятка не заменяет правила: при расхождении главнее файл по ссылке.

Уровень: **О** — [ОШИБКА], **В** — [ВНИМАНИЕ], **И** — [ИНФО]. Это уровни каталога тегов (`approaches/process/review-tags.md`, `stacks/go/review-tags.md`; безопасность — `approaches/process/security.md`): по ним же судит ревью; при расхождении пометки с каталогом главнее каталог.

## Слои и место кода

1. **О** Файл лежит по `structure.md` (таблица путей, чеклист модуля); имя файла = что в нём объявлено, не `ports.go` (`interface-file-generic-name`; файлы групп интерфейсов модуля домена — `conventions.md` п. 12). **В** `utils.go`/`types.go`/`const.go` — `file-named-by-abstraction`, `conventions.md` п. 13. — `conventions.md` п. 12, 13, 16
2. **О** Зависимости слоёв: домен не знает HTTP/БД/workflow, entrypoint не знает bootstrap. — `architecture/layers.md`
3. **О** Service/Command/Query — только свой домен; 2+ домена → workflow; workflow берёт репозитории и сервисы любых доменов напрямую. Из домена чужой домен (сервис, репозиторий, сущность, enum) не импортируется: понятие двух и более доменов — `internal/common/` (enum, value-объекты, чистые функции; без DI и I/O); копия понятия — `duplicated-enum`, логика в `internal/common/` — `common-with-logic`. — `architecture/layers.md` (O-7), «Общий бизнес-словарь»
4. **О** Хендлер тонкий: биндинг/формат → маппинг → сервис/workflow; формат входа — id > 0 (невалидный id пути — 422, `go-sdk/exceptions.md`), границы у чисел и массивов (`page` — `lte=10000`, `per_page` — `lte=100`; правила — в теге `binding`, тег `validate` SDK не читает, `validate-tag-ignored`), enum (`regulations/rest-api.md`, «Валидация входа»). Роль/право на операцию — middleware на маршруте (`RequirePermissionMiddleware`); доступ (здание/организация) — middleware контекста, в сервис — фильтром. Проверок ролей/прав в хендлере и домене нет. — `conventions.md` п. 7
4a. **О** PUT — полные данные: каждое поле обязательно к передаче, неприсланное — 422 (O-10); частичное обновление — `PATCH` с DTO `Patch` на указателях (`nil` — поле не меняется; эталон — `tariff` `Update`). — `regulations/rest-api.md`, «Методы», «Валидация входа»
4b. **О** PUT/PATCH статус не меняют: поле состояния в запросе изменения и общий «сменить статус» — нет, переход — свой эндпоинт и Command (`status-in-update-request`). — `regulations/rest-api.md`, «Методы» (O-28)
5. **О** Бизнес-логика только в сервисах/Command/workflow; маппер только маппит (nil-check входа первым — `go-sdk/infra.md`, «Правила»), репозиторий только запросы. — `conventions.md` п. 6, 15
5a. **В** Значения входа DTO — `{entity}_validator.go` (O-18); правила состояния и переходов — методы сущности (`CanArchive()`/`Archive()`); не inline в сервисе, Command, workflow (`invariants-inline`). — `regulations/entity.md` (O-26)
5b. **О** Новая сущность: поле состояния неэкспортируемое, геттер, метод на каждый переход, сборка из БД — `Restore*` (`state-field-exported`); запись перехода — свой метод репозитория с условным `UPDATE`, 0 строк — 422. — `regulations/entity.md`, «Переход состояния» (O-28)
6. **О** Хранилища (БД, Redis, HTTP, файлы) — только через репозитории `internal/infrastructure`; исходящий HTTP — только `gosdk-http-request-builder`; репозиторий только запросы, «не найдено» — `nil, nil`, без `FindOrCreate`. — `conventions.md` п. 4, 5; `architecture/layers.md`, «Правила слоёв»
7. **О** Интерфейс объявляет потребитель, не инлайном; вне модуля домена и workflow — в файле по имени интерфейса; конструктор возвращает конкретный тип. **В** В модуле домена и workflow — в файле своей группы (у workflow без `modules.go`): `repository.go` — данные (хранилища и внешние системы как источник данных), `tx_manager.go` — транзакции, `modules.go` — соседние модули домена, `system.go` — технические сервисы без данных домена (время, ID, отправка событий и сообщений). — `conventions.md` п. 10–12
8. **О** Workflow собирается в `workflows_factory.go`, файл `{действие}_workflow.go`, метод `Exec`; другие workflow не вызывает (`workflow-calls-workflow`), запросов к таблицам не пишет. **В** Свой порт внешней системы — только если его нет в домене (`workflow-duplicates-domain-port`). — `go-sdk/workflow.md`
9. **О** Домен не строит `map[string]any` с колонками БД: частичное обновление — DTO `Patch` + маппер в инфре. — `core/style.md`, «Данные между слоями»
10. **В** DTO, константы, enum (`{name}_enum.go`), интерфейсы — в своих файлах, не в файле сервиса; 4+ аргумента у функции (не конструктора; `ctx` не в счёт) → `Params` в `dto.go` (`core/style.md`, «Форма кода»). — `conventions.md` п. 13
48. **В** Запрос репозитория виден целиком: без функций-фрагментов и констант колонок, фильтры — в том же методе; подзапрос — не больше чем в 2–3 методах, join и простые `WHERE` — свободно; большой запрос по чужим таблицам — несколько методов репозиториев, сервис/workflow собирает их готовые результаты (запросов в нём нет). — `architecture/layers.md`; `conventions.md` п. 15a
49. **О** Метод репозитория — один запрос: «выбрать и записать», «заблокировать и удалить», «прочитать и сохранить» — два метода, порядок и `txManager.Exec` — в сервисе/Command/workflow; ручной `client.Transaction` в репозитории — нет. — `architecture/layers.md`; `conventions.md` п. 15b

## SDK

11. **О** Что есть в SDK — не пишется заново (`sdk-reimplemented`); вызов сверен с `go-sdk/reference/{gitlab|github}/` (источник и версия проекта); чего нет в справочнике — нет в SDK. — `go-sdk/capabilities.md`
12. **В** Источник и версия SDK записаны в `design.md` («SDK»): из `go.mod`, у нового проекта — ответ пользователя. — `conventions.md` п. 23 (O-4)
13. **О** Для не-бизнесовой проблемы (транспорт, сериализация, ретраи, скелет consumer'а) уже есть общий компонент (`pkg/` проекта, SDK) — только он, своя реализация даже в первый раз — переизобретение (`infra-logic-duplicated`, `duplicated-handler-skeleton`; в SDK — `sdk-reimplemented`). **В** Третья копия — вынести в `pkg/`. **И** Вторая копия — кандидат на вынос, оба места — в итог. Повтор в домене — не находка (O-25). — `core/principles.md`, «Инфраструктурный код — один раз»; `conventions.md` п. 22

## Транзакции

14. **О** Больше одного модифицирующего запроса в сценарии — в одном `txManager.Exec`. **В** Один — без транзакции (`needless-transaction`), кроме блокировки. — `approaches/patterns/transactions.md` (O-8)
15. **О** Проверка перед записью: состояние связанной записи (активна, не удалена) — до транзакции; чтение своей записи внутри `fn` — допустимо, через репозитории из аргументов (`go-sdk/infra/postgres.md`, «Транзакции»; эталон — `SetDefaultTariffCommand`). От гонки защищает не то, что лежит в транзакции, а решение «Конкурентность» `design.md` (п. 25): уникальный индекс, условие в `UPDATE`, внешний ключ (существование); состояние связанной записи — `FOR SHARE` в транзакции или принятый риск с ответом пользователя (теги `race-on-related-state`; принятый без ответа — `race-risk-accepted-silently`). — `approaches/patterns/transactions.md` (O-8), `concurrency.md`
16. **О** Внутри `fn` — только репозитории из аргументов; сервис/Command домена или репозиторий из поля пишут мимо транзакции. — `go-sdk/infra/postgres.md`
17. **О** В транзакции нет HTTP, публикаций, `sleep`; сброс кэша и побочные эффекты — после коммита, гарантия доставки — outbox.

## Контекст, ошибки, конкурентность

18. **О** `ctx` — первым параметром в методах с I/O и вызывающих их, по цепочке; `context.Background()`/`TODO()` в бизнес-коде нет; ctx не хранится в структуре (`context-not-propagated`). — `conventions.md` п. 1, 2
19. **О** Запрос к БД/Redis — с таймаутом (`context.WithTimeout`; у пагинатора и транзакции SDK встроен; `SetTimeout` пагинатора — число секунд, `SetTimeout(10)`, тег `paginator-timeout-units`). — `approaches/patterns/performance.md` (`query-without-timeout`), `review-findings.md`, «Контекст»
20. **О** Ошибки не игнорируются (`_ =`); технические — обёрнуты с ID (`%w`); бизнес-ошибки — `AppException` SDK, по-русски. — `conventions.md` п. 8, `go-sdk/exceptions.md`
21. **В** Намеренно не проброшенная ошибка — `errorreporter.CaptureSoft/CaptureError`, не только лог; проба healthcheck — причина в `logger.Warning` без трекера. — `conventions.md` п. 19
22. **О** `panic` — только при старте приложения; обязательная настройка отсутствует — не стартуем, не дефолт; хосты нормализуются при чтении конфига. — `conventions.md` п. 9; `regulations/service-requirements.md`, «Конфиг»
23. **О** `go` — там, где решают про асинхронность (workflow/entrypoint), не внутри сервиса; побочный эффект после записи — outbox, не fire-and-forget. — `conventions.md` п. 18
23a. **О** Consumer тонкий и идемпотентный: payload → DTO → сервис/workflow; ошибка десериализации — ACK, временная — NACK; топология — при старте через SDK. — `approaches/patterns/async.md`, «Consumer», `go-sdk/entrypoint/rabbit.md`
24. **О** `nil` вместо обязательной зависимости в конструктор не передаётся. — `conventions.md` п. 21
25. **О** Конкурентные места из `design.md` закрыты: уникальный индекс + перехват `23505` → 422, условный `UPDATE` статуса, идемпотентность, блокировка крона; общее состояние — без data race (`go test -race`). — `approaches/patterns/concurrency.md`
26. **О** Без N+1, список с пагинацией, индекс под фильтр/сортировку, массовые операции пачками. — `approaches/patterns/performance.md`
26a. **В** Список: сортировка явная и стабильная (ключ или дата + `id`); каждое поле запроса → поле фильтра → условие, и наоборот (`request-filter-not-applied`). Go: поле `request.go` → поле `Search` (маппер) → `Where` и явный `Order(…, id)` в замыкании `Paginated`; сортировка клиента — `oneof` допустимых полей в `binding`, в `Order` — по белому списку, не строкой из запроса. — `regulations/rest-api.md`, «Валидация входа»; `go-sdk/infra/postgres.md`, «Пагинация»
27. **О** Имя обещает ровно то, что делает код (`Enqueue`/`dispatch` без очереди — нет; `service-method-name-mismatch`). — `conventions.md` п. 20

## Безопасность

28. **О** Каждый хендлер ресурса скоупит по владельцу — отдельно `get`/`update`/`delete`, не только список; скоуп — тип с явным `All` (`ParkingScope`), не `[]uint` с `nil`; id владельца из запроса — 403 в middleware (на маршрутах с телом — строгое тело), по ID записи — чужая 404, кэш по ID — сверка после чтения. — `conventions.md` п. 7a; `architecture/layers.md`, «Принадлежность записи скоупу — два случая»; `security.md`
29. **О** Новый роут без auth-middleware — только осознанно, с причиной в MR. — `review-findings.md`, «HTTP-роуты»
30. **О** Вебхук/колбэк — проверка подписи по протоколу провайдера до смены статуса; повтор события не создаёт вторую запись; платёжный путь — все пункты `payments.md`. — `security.md`, `approaches/patterns/{idempotency,payments}.md`
31. **О** Нет SQL-конкатенации, секретов в коде/логах/общем Redis, внутренних деталей в ответе; техническая ошибка SDK текстом в `message` — **В** (`internal-details-leak`, сверка 2026-10-20), способ — выбор разработчика. — `security.md`, `go-sdk/exceptions.md`
32. **О** Меры из `threats.md` по своим файлам реализованы.

## Оформление

33. **О** `gofmt`; импорты тремя группами (std / внешние / свои).
34. **В** Ресиверы — одна буква; аббревиатуры заглавными (`ID`, `URL`, `DTO`; `initialism-case`).
35. **В** Пустая строка перед `return` (кроме первой строки блока; `missing-blank-before-return`) и между логическими блоками; builder из 3+ вызовов — по вызову на строку. — `style.md`
36. **В** Doc-комментарий на публичных типах и полях сущностей/моделей — только если добавляет смысл к имени; формат `Имя Описание по-русски`; комментарии-пересказы и «ИИ-шные» простыни — нет. Любой текст для людей (Swagger, ошибки клиенту, коммиты, ответы в MR) — по делу, без «ИИ-воды»; нигде нет Claude/ИИ как автора или соавтора (`Co-Authored-By: Claude`, «Generated with Claude Code»). — `core/style.md`, «Комментарии», «Любой текст для людей»
37. **В** Swagger перегенерирован при изменении роутов/DTO.
47. **В** Читается сверху вниз: вызов не вкладывается в вызов и не индексируется на месте (один уровень с коротким аргументом — допустим), замыкание не передаёт поведение в свою функцию, без затенения значимых имён (идиомы `if err :=` и `ctx` у `fn` транзакции SDK — допустимы), глубина блоков ≤ 2. — `core/style.md`, «Форма кода»; `style.md`

## Тесты и проверка

38. **О** Unit-тесты на правила R*, ветки ошибок и кейсы `qa.md` уровня unit — рядом с кодом, фейки по интерфейсам (`testsupport/*fakes`, фейк транзакции — `txfakes`). — `structure.md`, «Тесты»
39. **О** Прогнаны сборка, `vet`, тесты, `gofmt` (с горутинами — `-race`); вывод показан. Не запускал — так и написано. — `approaches/process/self-check.md`, строка Go
40. **О** Связи: по каждому изменённому символу/роуту/таблице/enum найдены использования (имя + строковый литерал); новое значение статуса/enum — во всех `switch`/`map`/swagger `enums`. — `approaches/process/impact-analysis.md`
40a. **О** Миграция — строго по «Схеме БД» `design.md` (согласована); расхождение — снова согласование, не правка по месту. — `regulations/technical-approval.md`, «Схема БД»
40b. **О** Миграция обратно совместима (expand/contract), FK явно (с поведением на `UPDATE`/`DELETE`), порядок выкатки и откат описаны. — `approaches/patterns/migrations.md`
41. **О** У нового статуса есть обработчик (крон/consumer/переход), иначе тупик. — `approaches/process/impact-analysis.md`, `approaches/patterns/payments.md`

## Действия агента

42. **О** Миграции, сиды, массовые правки, очистка, пересоздание схемы — не запускать без явного «да» на каждую. — `core/principles.md`, «Действия с БД»
43. **О** Пробел или спор — не решать молча: вопрос или решение по политике `/dev` + строка в `rules-log.md`. — `core/principles.md`
44. **О** Коммит и пуш — только по явному «да» на каждый.
45. **И** Ранний выход вместо `else`/`else if`: ветка с `return`/`continue` — и дальше без вложенности; выбор по значению — `switch`. — `core/style.md`, «Форма кода», `style.md`
46. **В** Преобразование формата (телефон, ИИН, карта, деньги, даты) — один раз: сначала SDK (`validation.NormalizePhoneNumber`…), потом `pkg/`; вторая копия — вынести, не копировать; inline при готовом в SDK или `pkg/` — **О** (`duplicated-format-logic`); в сервисе/репозитории преобразований формата нет. — `core/principles.md`, «Повторяющаяся обработка — один хелпер», `structure.md`
