## 2026-10-22
### Добавлено
- Вопрос об обратной совместимости при любой правке существующего (O-29): изменение контракта — всегда пункт Фазы 2 `/dev`, остальное — при потребителе вне сервиса (`impact-analysis.md`, «Обратная совместимость»); тег ревью `contract-change-unasked` [ОШИБКА] / [ВНИМАНИЕ] (без `design.md`).
- `/dev-rule` и `/dev-fix`: перезапуск сессии на границе шагов при контексте больше ~250 тыс. токенов или после сжатия — как в `/dev`.
- Go: Swagger на проде — `SWAGGER_ENABLED` в gosdk-http-core ≥ v1.1.0 (GitLab; по умолчанию выключен), строка в `go-sdk/capabilities.md`; эталон Go — http-core v1.1.0, core v1.0.10, Go 1.27.3, `SWAGGER_ENABLED` в `.env.example`; справочник GitLab пересобран. - Тег `outdated-runtime` [ВНИМАНИЕ]: дифф вводит версию языка, рантайма или базового образа — поддерживаемую и на последнем патче (`review.md`, гигиена MR).
- Продолжение после `/clear` и в новой сессии без повторного `/dev <ключ>`: `/dev`, `/dev-fix`, `/dev-mr`, `/dev-rule` (разбор лога, сверка) ставят метку задачи, хук `SessionStart` (ставит `install.sh <проект>` в `.claude/settings.local.json` проекта) подсказывает новой сессии незаконченную команду — пользователю хватает «дальше»; `/dev` без задачи продолжает незаконченную (`tools/resume/resume.py`).
- `/dev-fix`: шаг «Испорченные данные» — что баг успел записать (БД, кэш, события, внешние системы), как найти и чем вернуть; предложение пользователю, выполняется по «да»; тег ревью `bugfix-damaged-data-unaddressed`.
- `tools/usage/usage.py`: стоимость в единицах цены входа (по TTL записи кэша и модели), перезапись кэша после паузы, контекст оркестратора в конце; `--context` — размер контекста текущей сессии.
- `install.sh` печатает пример разрешений на чтение и тесты для `.claude/settings.json` проекта (пока агент ждёт подтверждения, его кэш остывает).

### Изменено
- `/dev-rule`: правка, меняющая установку, команды, инструменты или порядок работы, обновляет и `README.md`; независимое ревью правки проверяет `CHANGELOG.md` и `README.md`.
- `/dev`: перезапуск сессии на границе фаз уже при контексте больше ~250 тыс. токенов (`usage.py --context`), не только после сжатия; разбор лога правил и `/dev-mr` — в новой сессии; оркестратор не читает транскрипты агентов и артефакты целиком.
- Доводка закончившегося агента — не позже 5 минут после его итога, позже — свежий агент.

### Изменено
- Swagger: пропущенный или лишний код ответа (в т. ч. от middleware маршрута) — [ВНИМАНИЕ] в обоих стеках, тег `swagger-status-mismatch` (PHP — пункт памятки 24a, его же ставит проверка маршрутов `403` у `permission:`); эндпойнт без Swagger вовсе — PHP `controller-missing-swagger` [ОШИБКА].
- Умолчание производного фильтра списка описывается текстом в описании параметра, без `default` в схеме OpenAPI.
- `too-many-params`: не находка — до 3 позиционных + DTO опций последним и приватный шаг длинного метода до ~5 параметров.
- Скоуп в условии самой записи (`UPDATE … WHERE id = ? AND parking_id IN (…)`) без чтения — тоже проверка доступа.
- Скоуп при изменении: доступ проверяется чтением со скоупом, запись после этого — по `id`; ревью не ставит находку за `Update(id)` после такой проверки.
- `page` 0 или не передан приводится к 1 при разборе запроса, до расчёта смещения; Go-эталон — в маппере точки входа.
- Маппер на `nil`: выход-указатель — `nil`, выход-коллекция — пустая коллекция, выход-значение — нулевое значение, Request — по значению без проверки.
- В счёт «4+ аргумента» не входят `ctx` и `t`/`b`/`f` тестов Go; комментарий порта — что делает, без проводки и истории.
- Go: имена-абстракции файлов, которые ловит анализатор, — ещё `constants.go`, `consts.go`, `helpers.go`, `common.go`, `misc.go`; исключение из «ошибки не игнорируются» — ещё `errorreporter.CaptureError`.
- Go: константы модуля — в одном `enum.go` вместо `{name}_enum.go`; `internal/common/` — по-прежнему файл по понятию.
- Go: имена файлов — обязательные строго по `structure.md`, вспомогательный допустим с именем по содержимому (было: любое отклонение — ошибка).
- Go: консоль — свой bootstrap `internal/console/bootstrap/{domain}/{module}/`; серверный `module.go` больше не держит `Console`.
- Повтор шагов в Service, Command/Query, Workflow — не находка; `duplicated-handler-skeleton` — только инфраструктура, уровни по числу копий.
- Значения входа — в валидаторе DTO, правила состояния — в методах модели; выбора «валидатор или сущность» в `design.md` больше нет.
- `infra-logic-duplicated`: вторая копия — [ИНФО], третья — [ВНИМАНИЕ] (было [ОШИБКА]); тег и `invariants-inline` — в общем каталоге.
- README переписан по правилу «Любой текст для людей»: актуален (анализаторы на проекте, выбор PHP-контейнера, инструменты, `CHANGELOG.md`), без пересказа других файлов.
- `lint.py` в конце полного прогона печатает «Остаток — проверить глазами»; ревьюер `/dev` больше не читает `RULES.md` целиком.
