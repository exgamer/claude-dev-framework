# fix-default-tariff: активный тариф нельзя назначить тарифом по умолчанию

## Симптом

Сообщение из поддержки (как пришло):

> В админке у парковки два тарифа, оба активные, по умолчанию — первый. Пытаемся сделать вторым по умолчанию:
> `POST /api/admin/v1/billing/tariffs/{id}/set-default` отвечает 422 `{"id": "отключённый тариф нельзя сделать тарифом по умолчанию"}`.
> Тариф не отключён — в таблице `tariffs` у него `is_active = true`, им пользуются.

Ожидаемое: активный тариф становится тарифом по умолчанию своей парковки, прежний теряет флаг (описание эндпойнта в Swagger, `set_default_tariff_command.go`).
