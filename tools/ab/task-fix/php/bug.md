# fix-default-tariff: у других парковок пропадает тариф по умолчанию

## Симптом

Сообщение из поддержки (как пришло):

> Оператор назначил тариф по умолчанию на одной парковке (`php artisan billing:tariffs:set-default {id}`).
> После этого у всех остальных парковок тарифа по умолчанию больше нет: новые стоянки на них не находят тариф.
> На самой парковке, где назначали, всё правильно.

Ожидаемое: назначение тарифа по умолчанию меняет флаг только у тарифов его парковки — новый получает флаг, прежний этой парковки теряет; тарифы других парковок не меняются (описание команды, `SetDefaultTariffCommand`).
