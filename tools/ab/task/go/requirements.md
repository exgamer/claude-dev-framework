# Архивация тарифа — требования

- R1 Админ архивирует тариф: `POST` на тариф по id `/archive` рядом с маршрутами тарифов админки, право — как у изменения тарифа.
- R2 Архивный тариф не возвращается в списке админки по умолчанию; `archived=1` — только архивные.
- R3 Тариф по умолчанию архивировать нельзя — 422; повторная архивация — 422; тариф не найден в скоупе парковок пользователя — 404; невалидный id — 422.
- R4 Архивный тариф нельзя назначить тарифом по умолчанию — 422 (инвариант «тариф по умолчанию не архивный»).

Критерии приёмки: AC1 — R1 возвращает тариф/успех и пишет `archived_at`; AC2 — R2 оба варианта списка; AC3 — каждый код из R3; AC4 — R4. Unit-тесты на правила R3, R4.
