# Внешние интеграции

---

- Внешняя система (платёжка, фискализация, камеры, СКУД, партнёр) — **адаптер в Infrastructure, путь которого — по внешней системе**, а не по нашему домену (имена типов — по роли, п. ниже): `infrastructure/http/{provider}/{product}` (Go) / `Infrastructure/Http/{Provider}/{Product}` (PHP). Реализует интерфейсы потребителей — доменов и workflow, если порта нет в домене (`layers.md`, «Зависимости»); один адаптер может обслуживать несколько потребителей. Свои БД/кэш — по `{domain}/{module}`. Полная таблица — `stacks/go/go-sdk/infra.md`, «Раскладка по типу». Домен и сервис не знают про HTTP.
- **Имена порта и адаптера — по роли для кода-потребителя, без имени поставщика и технологии** (В-18). Источник данных (прочитать, сохранить, проверить — модуль получает данные в ответ) — `…Repository` (PHP — `…RepositoryInterface`): `PriceLimitRepository`. Отправка, уведомление, публикация без данных в ответ — по действию: `…Notifier`, `…Publisher`, `…Sender` (`TariffNotifier`). Имя внешней системы — только в пути адаптера (`Http/{Provider}/{Product}`); класс адаптера — по той же роли: Go — `HTTPRepository` в `repository.go` / `HTTPNotifier` в `notifier.go`, PHP — `{Provider}{Product}Repository` / `{Provider}{Product}Notifier` (+ `Mocks/…Mock`). `Gateway`, `Client`, `Service` и имя системы в имени порта (`CityParkingPriceLimitsGatewayInterface`) — нет. Граница «данные / отправка» — та же, что у файлов `repository.go` / `system.go` (`stacks/go/conventions.md` п. 12, G-6). Эталоны — `stacks/go/examples/tariff/internal/infrastructure/http/`, `stacks/php/examples/parking_app/Infrastructure/Http/`.
- Клиент (HTTP, SDK партнёра) не создаётся внутри репозитория — инжектируется через DI. Если инструмент стека создаёт клиент сам (Go `gosdk-http-request-builder`), инжектируются адрес и таймаут из конфига — `stacks/go/go-sdk/infra/http.md`, «repository.go».
- Исходящие HTTP — только через инструмент стека (`gosdk-http-request-builder`; в PHP — клиент из `mps/utils` или интеграционный пакет `mps/*-service-integration`). Голый `http.Get` / `Http::get` — нет.
- На уровне системы: **одна интеграция — один сервис/модуль**. Несколько несвязанных внешних систем за одним «integration-service» не собираются; бизнес-сервис не ходит во внешнюю систему напрямую.
- Входящие вебхуки и машинные вызовы — отдельный контекст точки входа (`integration`), проверка подписи — middleware контекста (Go — `SignatureAuthMiddleware` в `stacks/go/examples/tariff/internal/entrypoints/integration/http/middleware/signature_auth.go`, PHP — `stacks/php/examples/parking_app/Core/Http/Middleware/VerifySignatureMiddleware.php`).
- Таймауты, ретраи, идемпотентность — `approaches/patterns/`.
- Секреты интеграций — только из конфига/env; в БД — зашифрованными (как `FiscalCredentialEncrypter`).
- Новая внешняя система или протокол — согласование до кода (`regulations/technical-approval.md`).
