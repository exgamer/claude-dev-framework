# Идемпотентность и повторы

- **Входящие вебхуки/колбэки** (платёжки, железо) — идемпотентны: повтор того же события не создаёт вторую запись и не меняет статус повторно. Ключ — внешний ID события/транзакции + уникальный индекс в БД.
- **Consumer** обрабатывает сообщение так, чтобы повторная доставка была безопасна (at-least-once).
- **Переход статуса** — проверка текущего статуса в сервисе перед переходом; финальный статус не перезаписывается.
- **Исходящие повторы** — только для временных ошибок; число попыток и задержка — в конфиге; постоянная ошибка не ретраится.
- **GET-ретрай** не повторяет запрос, упавший по таймауту ответа (медленный бэкенд получит двойную нагрузку).
