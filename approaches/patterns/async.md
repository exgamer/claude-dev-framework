# Асинхронность

- Асинхронность решает **вызывающий** код (workflow, entrypoint, runner), а не сервис внутри себя. Скрытая горутина/`dispatch` в сервисе, если это не его контракт, — `hidden-async-in-service` (`stacks/go/conventions.md`, п. 18).
- Go: горутина с явным lifecycle (кто ждёт, как остановить, куда ошибка/паника), контекст — от app, не `context.Background()`.
- PHP: очередь — RabbitMQ V2 (`QueueManagerInterface`), отложенное действие — `Job::dispatch(...)->delay(...)` после записи.
- «На всякий случай» асинхронно не делается: нужна причина (долго, внешняя система, развязка доменов).
- Событие наружу с гарантией доставки — `outbox.md`.

## Consumer (обработчик сообщения очереди)

Точка входа (`architecture/layers.md`: слой Entrypoint), как контроллер, только вход — сообщение. Стек: Go — `stacks/go/go-sdk/entrypoint/rabbit.md`, PHP — `stacks/php/mps-core/jobs.md`.

- **Тонкий:** десериализация payload → DTO → один вызов сервиса/workflow. Бизнес-логики нет; доменные инварианты проверяет валидатор в сервисе/workflow (`workflow-trusts-transport-request`).
- **Payload — внешние данные:** через DTO с проверкой обязательных полей, не доступ к ключам массива/`map` напрямую (PHP п. 11b `array-key-unchecked`).
- **Идемпотентен** (`idempotency.md`): доставка at-least-once, повтор не создаёт вторую запись и не меняет статус повторно — проверка текущего состояния до действия, уникальный индекс по внешнему id события.
- **Ошибки двух типов** (`outbox.md`): временная (внешняя система недоступна, сеть) — исключение/`error` наверх, сообщение повторяется; постоянная (битый payload, нет конфигурации, запись не найдена и не появится) — зафиксировать (статус, лог, трекер) и подтвердить сообщение, иначе повтор бесконечный. Ошибка десериализации — постоянная.
- **Топология** (exchange, очереди, bindings, DLX) объявляется при старте приложения через ядро/SDK, не лениво в consumer и не своим соединением с брокером (`outbox.md`, «Нельзя»).
- **Параллелизм** — `prefetch`/число воркеров по нагрузке (`performance.md`, `consumer-unbounded`); несколько воркеров на одну очередь записей — `SKIP LOCKED` (`concurrency.md`).
- **Ручные `ack`/`nack`** там, где результат обработчика их уже выражает, не пишутся.
